# Character Studio — معرض أعمال رسام شخصيات

معرض أعمال عربي RTL باستخدام HTML وCSS وJavaScript وBootstrap 5، دون إطار عمل JavaScript.

## تشغيل المشروع
- افتح `index.html` في المتصفح، أو استخدم إضافة Live Server في VS Code.
- يحتاج اتصالًا بالإنترنت لتحميل Bootstrap وخط Cairo من CDN.

## إضافة صورك
ضع الصور في `assets/images/` بالأسماء التالية:
- `hero-character.jpg` — الصورة الرئيسية.
- `work-01.jpg` إلى `work-06.jpg` — صور الأعمال الستة.

يمكنك استخدام صور PNG أو WebP أيضًا، لكن عدّل مسارات الصور في `index.html` لتطابق أسماء الملفات.

إذا لم تضع صورة بعد، ستظهر مساحة بديلة توضح مكان الصورة.

## تعديل النصوص والروابط
- العنوان والوصف وعناوين الأعمال في `index.html`.
- روابط Instagram وBehance والبريد الإلكتروني قرب نهاية `index.html`.
- لتغيير ألوان الموقع، عدّل متغيرات `:root` في بداية `style.css`.

## تخصيص تصنيف الأعمال
كل عنصر يحمل `data-category` بقيمة `character` أو `concept` أو `color`. حافظ على هذه القيم أو عدّلها مع أزرار التصفية.

## النشر على GitHub Pages
1. ارفع ملفات المشروع إلى مستودع GitHub.
2. افتح Settings → Pages.
3. اختر النشر من الفرع `main` والمجلد `/ (root)`.
4. احفظ وانتظر ظهور رابط الموقع.

## ملاحظات
- لا يوجد Backend أو قاعدة بيانات؛ هذا معرض عرض فقط.
- نافذة Bootstrap تعرض العمل بالحجم الأكبر عند الضغط على البطاقة.
- تم دعم الشاشات الصغيرة وتفضيل تقليل الحركة في إعدادات النظام.
